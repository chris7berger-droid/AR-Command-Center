AR Command — Handoff v3 (2026-04-14)
======================================

## What Changed This Session

### New: Decision Engine (Commit 5935cf8)
- When an invoice is triaged as Problem or Unsure, a ReasonPicker appears
  with 7 options: Won't Pay, Overbilled, Retention Dispute, Quality Dispute,
  Misapplied Payment, Partial/Short Pay, Don't Know
- Selecting a reason auto-recommends a QB action (write-off, credit memo,
  retention hold, negotiate, fix payment, chase difference, send to accountant)
- PlaybookPanel shows the recommendation with:
  - Cash-basis tax impact notes
  - Click-by-click QB steps personalized with invoice #, amount, customer name
  - Override option to pick a different action
  - Confirm button ("Got it — I'll do this")
- Decisions persist in localStorage (ar7-decisions) keyed by invKey
- "Action Set" badge appears on confirmed invoices in the card header

Files added:
- src/lib/decisionEngine.js — Core engine, reuses daysOverdue/fmt from utils.js,
  frozen lookup tables, pre-built static reason→action map
- src/components/QBPlaybook.jsx — ReasonPicker + PlaybookPanel (React.memo wrapped)

Files modified:
- src/lib/arStore.js — ar7-decisions key + load/save
- src/lib/ARContext.jsx — decisions state + updateDecisions + provider
- src/pages/TriageTab.jsx — Decision engine integration in expanded InvCard

### New: Cash Basis Banner (Commit 5dc0de2)
- Dismissible/expandable educational banner on Triage + Chase tabs
- Explains zero tax impact of write-offs, credit memos, payment reassignment
- 2x2 grid of quick explanations, expandable for detail
- File: src/components/CashBasisBanner.jsx

### New: Accountant Review Export (Commit 5dc0de2)
- Export button on Triage tab now reads "Accountant Review"
- Generates printable HTML + CSV report bundling:
  - Invoices flagged "Accountant Review"
  - Invoices with "Don't Know" decision reason
  - Invoices triaged "Unsure" with no decision yet
- Each item shows: aging badge, flags, customer, job, dates, overdue days,
  "MY ASSESSMENT" block with issue + suggested action, and recent notes
- Includes accountant-facing intro explaining cash basis context
- File: src/lib/exportUtils.js (exportAcctReviewView function)

### New: Blinders Mode (Commit 5dc0de2)
- Chase tab (ActionPlanTab): toggle checkbox, on by default
  - Hides invoices triaged "Good" or with confirmed decision actions
  - Shows only invoices that still need attention
- Cash Flow tab (CFFTab): automatically excludes confirmed-decision invoices
  from the forecast (you already know what to do with them)

### Dashboard Wiring (Commit 5dc0de2)
- CashBasisBanner renders on triage + action tabs
- Triage export wired to exportAcctReviewView
- Topbar shows context-aware export button label
